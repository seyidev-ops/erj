A CV Builder Should Never Invent Your Career: What Safe Tailoring Looks Like

The job description should guide positioning, not rewrite history. Here is the boundary between useful targeting and dangerous automation.

Oluwaseyi Ashiru3 September 20266 min read

CV software can make a document cleaner. It can also make it less trustworthy if it is allowed to optimise blindly against a job description.

The job description is a comparison surface

Its job is to tell you what the employer appears to value. From there, the builder should identify which of those requirements are already supported by your real experience, skills and tools.

That is enough to improve positioning.

What safe automation may change

  • The professional headline, so the target function is clear
  • The order of skills you have already supplied
  • The order of tools you genuinely use
  • Prompts showing which existing evidence best supports the role

What it should not change automatically

  • Employers
  • Employment dates
  • Historical job titles
  • Achievement wording
  • The order of experience bullets simply to increase keyword similarity
  • Skills or tools you never confirmed

Why this boundary matters

A hiring process is not just a parsing test. Anything written on the CV can become an interview question. If the document says you led onboarding, you need to be able to explain the onboarding work. If it names a tool, you need to be able to use it.

The safest CV is not the one with the highest possible keyword density. It is the one that makes the strongest truthful case for this role.

Missing terms are useful information

If a vacancy repeatedly asks for stakeholder management and your CV contains no evidence of it, the answer is not automatically to insert the phrase. First ask whether you have done it under another name. If yes, translate the evidence. If no, it is a real gap.

A tool that tells you what is missing is often more valuable than one that silently fills it.

Someone's job is at stake. 'Optimise' is never permission to make their history prettier than it is.
